# snapbuild-task

Landing page recreation for the Snapbuild test task.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- ESLint + Prettier

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run format:check
npm run build
```

The first implementation stage intentionally contains no landing-page sections. It establishes the application, static deployment, and code-quality foundation before the design system is added.
